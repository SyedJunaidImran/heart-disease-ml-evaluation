# Heart Disease Prediction & Model Evaluation

A machine learning classification workflow built in Python (Google Colab) to predict heart disease and evaluate model performance using standard classification metrics and visualizations.

## Overview
- **Dataset:** Heart Disease Dataset (`heart.csv`) sourced from Kaggle
- **Preprocessing:** Missing value imputation (median), one-hot encoding for categorical features, 80/20 stratified train-test split, and feature standardization (`StandardScaler`)
- **Model:** Logistic Regression

## Evaluation Metrics & Visualizations
The notebook computes and visualizes:
- **Confusion Matrix** (True Positives, True Negatives, False Positives, False Negatives)
- **Accuracy, Precision, Recall, and F1-Score**

- `Disease_Prediction_Evaluation.ipynb` — Complete Colab notebook with data preprocessing, model training, metrics, and plots
